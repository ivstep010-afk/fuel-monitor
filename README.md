# GdeBenz Monitor

Мониторинг наличия топлива на заправках с сайта [gdebenz.ru](https://gdebenz.ru). Отслеживает появление/исчезновение бензина и изменение цен, отправляет уведомления.

## 🚀 Возможности

- **Мониторинг в реальном времени** - периодическая проверка заправок в выбранном городе
- **Умные уведомления** - только об изменениях (появилось/закончилось топливо, изменилась цена)
- **Гибкие фильтры** - по брендам, типам топлива, только работающие заправки
- **Множественные каналы уведомлений** - консоль, Telegram (расширяемо)
- **Сохранение состояния** - не уведомляет дважды об одном и том же
- **Интерактивная настройка** - удобный запуск через меню

### Интерактивная настройка при запуске:

1. **Выбор города** - из списка или ввод координат вручную
2. **Выбор брендов** - какие заправки интересны (Лукойл, Роснефть, Газпромнефть и т.д.)
3. **Выбор топлива** - какие марки бензина отслеживать (92, 95, 98, 100, ДТ, 95+)
4. **Интервал проверки** - как часто опрашивать API (по умолчанию 300 сек = 5 мин)

## 🔧 Как это работает

### API Endpoints используемые:

- `GET /api/nearby?lat={lat}&lon={lon}&radius_km={radius}` - заправки рядом с точкой
- `GET /api/stations?lat1={lat1}&lon1={lon1}&lat2={lat2}&lon2={lon2}` - заправки в прямоугольнике

### Алгоритм детекции изменений:

1. Получает список заправок для города
2. Фильтрует по настройкам (бренд, топливо, статус)
3. Сравнивает с предыдущим состоянием (сохранено в `data/state.json`)
4. Определяет изменения:
   - **appeared** - топливо появилось на заправке
   - **disappeared** - топливо закончилось
   - **price_changed** - изменилась цена
5. Отправляет уведомления через настроенные каналы
6. Сохраняет новое состояние

### Модель данных заправки:

```python
Station:
  - osm_id: str           # Уникальный ID
  - name: str             # Название
  - brand: str            # Бренд (Лукойл, Роснефть, Газпромнефть...)
  - lat, lon: float       # Координаты
  - address: str          # Адрес
  - status: str           # "yes" (работает) / "no" (не работает)
  - fuels_now: str        # Доступное топливо "92,95,ДТ"
  - prices: Dict[FuelPrice]  # Цены с подтверждениями и временем
  - detail: str           # Доп. инфо (очереди, лимиты)
```

## 🔮 Расширение

### Добавить новый канал уведомлений:

1. Создайте класс в `src/notifications/`, наследуясь от `NotificationProvider`
2. Реализуйте методы `send()` и `name()`
3. Добавьте в `setup_notifications()` в `main.py`

### Добавить новый город:

В `src/config/settings.py` в словарь `CITIES`:

```python
"mycity": CityConfig("Мой Город", 55.0, 37.0, 15.0),
```

## ⚠️ Важные замечания

- **Не спамьте API** - используйте разумные интервалы (минимум 60 сек, рекомендуется 300+)
- **User-Agent** - уже настроен на браузерный, не меняйте без нужды
- **Rate limiting** - сайт может блокировать при частых запросах
- **Данные** - берутся с gdebenz.ru, точность зависит от пользователей сервиса
